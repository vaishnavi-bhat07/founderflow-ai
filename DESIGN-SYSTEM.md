1. Colour Palette
FounderFlow AI will use a simple and modern colour theme to make the application look clean and easy to use.
Primary Colour: #4F46E5
Secondary Colour: #7C3AED
Background Colour: #F8FAFC
Text Colour: #111827
Accent Colour: #06B6D4
Success Colour: #16A34A
Error Colour: #DC2626
2. Typography
We will use the Inter font throughout the application because it is simple and easy to read.
Main Heading (H1): 32px, Bold
Section Heading (H2): 24px, Semi-Bold
Body Text: 16px, Regular
Small Text: 14px, Regular
Button Text: 16px, Medium
3. UI Components
The application will use reusable components to maintain a consistent design across all pages.
Navbar – For navigation.
Sidebar – For moving between application pages.
Button – For user actions.
Card – For displaying information.
Input – For entering user details.
Modal – For displaying forms and messages.
Task Card – For displaying tasks.
Progress Bar – For showing goal progress.
Badge – For displaying task status and priority.
Empty State – For showing when there is no data.
4. Design Style
The application will follow a clean, simple and modern design. We will use consistent spacing, rounded cards, clear buttons and easy navigation. The layout will also be responsive so that users can access the application on different screen sizes.
